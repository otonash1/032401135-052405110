# 校园失物招领

福州大学《软件工程与软件工程实践》2026 秋 结对作业（第二次之程序实现）。

基于第一次结对作业的原型设计，用 HTML + CSS + JavaScript 实现一个「校园失物招领」网页应用，
走通「发布信息 — 浏览或搜索 — 查看详情 — 联系发布者 — 更新状态」的完整流程。

## 目录结构

```
lost-found-app/
├── index.html          页面入口
├── css/
│   └── style.css       全局样式
├── js/                 业务脚本（数据、搜索、校验、界面）
├── assets/             图片与图标素材
└── README.md           目录说明与使用说明
```

## 使用说明

1. 下载本项目全部文件（保持目录结构不变）。
2. 用 **谷歌浏览器（Chrome）** 直接打开 `index.html` 即可，无需安装任何环境或启动服务器。
3. 数据保存在浏览器本地（localStorage），刷新页面不会丢失。

> 说明：本项目为纯前端实现，不依赖后端服务与第三方构建工具。
